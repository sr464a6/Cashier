## ✨ Features

| Module | Capabilities |
| :--- | :--- |
| 🔐 **Admin Login** | • Admin authentication<br>• Session-based login system<br>• Secure password verification |
| 👥 **Customer Management** | • Add customer data<br>• Edit customer data<br>• Delete customer data<br>• View customer information |
| 📦 **Product & Stock Management** | • Add products<br>• Edit product information<br>• Delete products<br>• Manage product prices<br>• Manage product stock<br>• Display low-stock products |
| 🛒 **Sales Transactions** | • Select customers & products<br>• Enter purchase quantity<br>• Automatically calculate subtotal & total price<br>• Automatically update product stock |
| 📋 **Transaction History** | • View completed transactions<br>• Search transactions<br>• View customer and product details<br>• Delete transactions<br>• Automatically restore stock when a transaction is deleted |
| 🧾 **Printable Receipt** | • Display transaction details<br>• Display customer information<br>• Display purchased products, quantity, and price<br>• Display total payment<br>• Print transaction receipt |
| 📊 **Dashboard** | Overview of:<br>• Total customers & total products<br>• Low-stock products<br>• Total transactions & total sales<br>• Recent transactions |
